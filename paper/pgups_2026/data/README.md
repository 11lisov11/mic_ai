# Данные к статье (FOC vs MIC AI)

В этой папке лежат артефакты, необходимые для воспроизведения численных результатов и рисунков статьи без RL-чекпойнтов.

Содержимое:

- `traces/` — исходные трассы моделирования (CSV) для 3 двигателей и 5 сценариев, отдельно для FOC и MIC AI.
- `scenario_metrics_multi_motor.csv` — метрики по всем комбинациям «двигатель—сценарий» (табличный источник чисел в статье).
- `motor_summary_multi_motor.csv` — агрегирование по двигателям.
- `regime_summary_multi_motor.csv` — агрегирование по сценариям/режимам.
- `study_summary_multi_motor.json` — сводка для отчета/статьи.
- `id_ref_headroom_table.csv` — таблица «потенциала оптимизации потока» (перебор $i_{d,ref}$ в FOC), использована в табл. 5 статьи.
- `time_to_foc_summary_ru.csv` — таблица «обучаемости» (время до уровней «не хуже/лучше FOC»), использована в табл. 6 и на рис. 6 статьи.
- `validation_report_pgups_2026.csv` — отчет валидации (пересчет метрик из трасс и проверка выполненной работы нагрузки).

Проверка корректности опубликованных чисел:

```bash
python tools/validate_pgups_study.py
```
