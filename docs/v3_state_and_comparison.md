# V3: текущий статус и сравнение (FOC vs MIC vs V3)

## 1) Текущее состояние проекта (по репозиторию + st.md)
- В репозитории есть цифровой двойник АД, базовый FOC и MIC (AI + rule-based), а также инструменты сравнения FOC vs MIC.
- В st.md зафиксированы новые обсуждения и численные результаты для метода V3 (TDN V3 / W3): троичная логика принятия решений на внешнем контуре скорости + троичный интегратор + троичный выбор потока, при сохранении PI-контуров токов.
- Метод V3 существует как прототип и доказательство концепции в st.md; в основной кодовой базе пока нет интегрированного контроллера V3.
- Принятые метрики: P_nom (средняя мощность на номинальном окне), E_in+ (положительная энергия за эпизод), MAE_nom и MAE_mid (ошибка скорости в двух устойчивых окнах).

## 2) Версия метода V3 (TDN V3 / W3) — формализация
Идея: внешний регулятор скорости принимает дискретные решения (−1/0/+1), а плавность создается интегратором решений, а не PI по ошибке. Энергосбережение достигается троичным управлением потоком.

Входы:
- omega_ref, omega (задание и текущая скорость)
- i_d, i_q (токи)
- psi_r (оценка потока, опционально)

Выходы:
- v_d, v_q (напряжения инвертора)

Алгоритм V3 (ядро):
1) Ошибка скорости: e = omega_ref - omega
2) Троичное решение:
   - u = +1 если e > deadband
   - u =  0 если |e| <= deadband
   - u = -1 если e < -deadband
3) Троичный интегратор решений:
   - Iu[k+1] = (1 - leak) * Iu[k] + u * dt
   - Iu ограничивается по модулю
4) Задание тока момента:
   - iq_ref = Kp * u + Ki * Iu
   - iq_ref ограничивается по модулю
5) Троичное управление потоком (энергетическая часть):
   - |iq_ref| > T_high  -> psi = psi_nom
   - |iq_ref| > T_mid   -> psi = psi_mid
   - иначе              -> psi = psi_min
   - id_ref = psi / Lm
6) Внутренний контур токов (классика):
   - v_d = PI_d(id_ref - i_d)
   - v_q = PI_q(iq_ref - i_q)
   - декомпенсация связей dq по стандарту FOC

Псевдокод:
```
e = omega_ref - omega
u = +1 if e > db else (0 if abs(e) <= db else -1)
Iu = clip((1 - leak) * Iu + u * dt, -Iu_max, Iu_max)
iq_ref = clip(Kp*u + Ki*Iu, -iq_max, iq_max)
psi = psi_nom if abs(iq_ref) > T_high else (psi_mid if abs(iq_ref) > T_mid else psi_min)
id_ref = psi / Lm
vd = PI_d(id_ref - i_d)
vq = PI_q(iq_ref - i_q)
```

## 3) Контекст эксперимента (из st.md)
- Модель: dq-модель АД с потоками psi_ds/psi_qs/psi_dr/psi_qr и ограничением по напряжению инвертора.
- Сценарий:
  - omega_ref: 0 -> 100 рад/с (t=0.1 c), затем 130 рад/с (t=1.2 c)
  - нагрузка: 0.5 (t<0.6 c), 1.5 (0.6–1.5 c), 0.8 (t>1.5 c)
- Временной шаг: dt = 1e-4, t_end = 2.0 c
- Окна для метрик:
  - Nominal: 1.7–1.95 c
  - Mid: 0.9–1.1 c

## 5) Где выигрываем / где проигрываем (с цифрами)
Выигрыши V3:
- Номинальная мощность: 125.5037 W (V3) vs 129.1066 W (MIC) -> −2.79% к MIC, −37.74% к FOC.
- Положительная энергия за эпизод: 338.8784 J (V3) vs 353.0660 J (MIC) -> −4.02% к MIC, −27.84% к FOC.
- Номинальная точность: MAE_nom 0.1434 rad/s (V3) на 1.44% лучше MIC.

Проигрыши V3:
- Точность на другом устойчивом участке: MAE_mid 0.3095 rad/s (V3) хуже MIC на +35.39%.
- Дискретность порождает ступенчатость и чувствительность к порогам (deadband/порогам потока).
- FOC сохраняет лучший эталон по точности и предсказуемости.

Ограничения интерпретации:
- P_nom и E_in+ отражают электрическую мощность/энергию в dq-модели без полного учета потерь инвертора и железа.
- Результаты относятся к конкретному сценарию и окнам измерения из st.md.
