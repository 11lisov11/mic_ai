# Отчет по подготовке репозитория к публикации

Дата: 2026-02-13

## Что сделано

1. Разделены исходники и артефакты прогонов.
2. Материалы статьи вынесены в отдельную папку `paper/pgups_2026/`.
3. В `.gitignore` добавлены правила, исключающие из публикации:
   - `outputs/` (результаты прогонов),
   - `results_run/` (обучение/чекпойнты),
   - `archive/` (локальный архив),
   - `docs/legacy_examples/` (крупные примеры/шаблоны).
4. Добавлены/обновлены тесты и workflow CI (`pytest` + smoke benchmark).

## Результат

- В репозитории остаются только исходный код, конфиги, тесты/CI и материалы статьи.
- Большие артефакты не попадают в git, но могут храниться локально для дальнейших прогонов/проверок.
